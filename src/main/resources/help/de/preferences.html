Geöffnet über Werkzeuge ▸ Einstellungen. Der Vollausschlag ist die geräteeigene Bereichskalibrierung, daher ist eine manuelle Kalibrierung nicht möglich: Der Kalibrierdialog öffnet sich schreibgeschützt und zeigt lediglich den eingebauten Vollausschlag der Karte für jeden Kanal.

Karte — Kalibrierungsprofile pro Karte

Die Vollausschlag-Kalibrierung — die Spannung in Volt RMS, die dem digitalen Vollausschlag ±1,0 des Wandlers entspricht, und damit die absolute dBV-Achse, die Spannungsanzeigen des Oszilloskops und der Ausgangspegel des Generators — gehört zur physischen Karte, nicht zum Backend und nicht zu dem Gerätenamen, den ein Treiber zufällig meldet. Ein Kartenprofil verknüpft diese Kalibrierung mit der Karte selbst und folgt ihr über die Backends hinweg, denn dieselbe Karte erscheint unter verschiedenen Namen — WASAPI umhüllt sie als Line (…) oder Speakers (…), WDM-KS meldet den bloßen Namen, ALSA hängt ein Suffix [plughw:…] an. Ein Profil führt eine einzige Liste erkannter Gerätenamen — die Namen und Namensfragmente, die diese Karte identifizieren — sodass eine einzige Kalibrierung ihr dient, ganz gleich, wie der Treiber das Gerät benennt.

Ein Profil hält an einer Stelle fest: den Namen der Karte; für welche Richtungen sie kalibriert ist (Bereitstellung: Eingang, Ausgang oder beides); ob sie einen oder zwei Kanäle hat (Kanäle: Mono oder Stereo); wie ihre beiden Kanäle je Richtung zusammenlaufen (Kopplung: Verknüpft oder Unabhängig); ihre Liste umschaltbarer Bereiche (Abschwächer- / Verstärkungs- / DIP-Stellungen); und den gemessenen Vollausschlag jedes Bereichs — stets pro Kanal gespeichert, da keine zwei physischen Kanäle exakt gleich kalibriert sind.

Alle Kartenprofile liegen in einer Datei devices.yaml, die neben Ihrer preferences.yaml im Benutzer-Datenverzeichnis abgelegt wird — nach demselben Muster der bearbeitbaren Kopien wie die Oberflächentexte und die Hilfedateien, die dort beim ersten Start angelegt werden und danach Ihnen gehören. Sie wird mit fertigen Profilen für einige bekannte Schnittstellen vorbelegt ausgeliefert (die E1DA Cosmos ADC, die JLsounds I2SoverUSB und die CUBILUX CB5), und alles, was Sie in diesem Reiter bearbeiten, wird dorthin zurückgeschrieben. Die Datei ist reiner Text und von Hand bearbeitbar, sodass Sie Karten auch außerhalb des Dialogs hinzufügen oder anpassen können.

Die Datei devices.yaml — Bearbeiten von Hand

Die Datei liegt im Benutzer-Datenverzeichnis, neben preferences.yaml:

BetriebssystemOrt
Windows%APPDATA%\Phonalyser\devices.yaml
macOS~/Library/Application Support/Phonalyser/devices.yaml
Linux~/.config/Phonalyser/devices.yaml

Es ist reines YAML. Die Datei beginnt mit einem Kopfkommentar und zwei Versionsmarken, dann folgt ein Block pro Karte. Eine kommentierte Karte mit jedem Schlüssel, den die Anwendung liest:

formatVersion: 1        # Kennung des Dateiformats — ändert sich nur, wenn sich das Schema selbst ändert
contentVersion: 2       # Katalog-Generation — steuert die einmalige Upgrade-Zusammenführung pro Release (siehe unten)
audioDevices:           # die Liste der Kartenprofile
  - name: E1DA Cosmos ADC          # logischer Profilname im Kombinationsfeld „Karte“ (erforderlich)
    match: [ "E1DA Cosmos ADC" ]   # erkannte Gerätenamen: Teilzeichenfolgen (ohne Groß-/Kleinschreibung), die diese Karte identifizieren
    input:                         # ein Block je Richtung — „output:“ hat dieselbe Form
      channels: INDEPENDENT        # MONO = ein Kanal; LINKED = zwei Kanäle, gemeinsamer Bereichsschalter; INDEPENDENT = zwei Kanäle, jeder eigener
      ranges:                      # eine Zeile je Eingangsstufen-Stellung (Abschwächer / Verstärkung / DIP)
        - { label: "1.7V", fsVrms: { left: 1.7, right: 1.7 }, calibrated: true }   # gemessener Vollausschlag pro Kanal; calibrated: true = diese Zeile von Ihnen gemessen (Upgrades überschreiben sie nie)
        - { label: "3.5V", fsVrms: { left: 3.5, right: 3.5 } }                     # ein noch nicht kalibrierter Bereich — weiterhin der voreingestellte Nennwert
      activeRange: { left: "1.7V", right: "3.5V" }   # INDEPENDENT: eine { left, right }-Zuordnung, je Kanal seine eigene aktive Zeile
  - name: I2SoverUSB
    match: [ "I2SoverUSB", "JLsounds" ]
    output:
      channels: LINKED
      ranges:
        - { label: "default", fsVrms: { left: 2, right: 2 } }
      activeRange: "default"       # LINKED / MONO: ein einzelnes Label (beide Kanäle schalten gemeinsam)

Was die Schlüssel bedeuten:

  • match ist die Liste erkannter Gerätenamen aus dem Karteneditor: jeder Eintrag wird als Teilzeichenfolge (ohne Groß-/Kleinschreibung) mit dem vom Treiber gemeldeten Gerätenamen abgeglichen, und wenn mehrere Karten passen könnten, gewinnt der spezifischste (der längste passende) Eintrag. Das Binden eines Geräts an eine Karte hängt den Namen dieses Geräts hier einfach an.
  • fsVrms ist der Vollausschlag des Bereichs in Volt RMS. Die Anwendung schreibt stets das Paar { left, right } — jeder Kanal trägt seinen eigenen gemessenen Wert — obwohl eine einzelne Zahl für beide Seiten gilt, wenn Sie eine von Hand eingeben.
  • calibrated: true markiert eine Zeile, die Sie tatsächlich über einen Kalibrier-Ablauf gemessen haben; die Upgrade-Zusammenführung überschreibt sie nie. Eine Zeile ohne dieses Flag ist weiterhin der voreingestellte Nennwert.
  • calibrationFromDevice: true (im Block input: oder output: hinzufügen) markiert eine Karte, deren Vollausschlag vom Instrument selbst gemeldet wird (ein Gerät der QA40x-Klasse): ihre Bereiche bleiben umschaltbar, aber die Anwendung schreibt nie eine Kalibrierung hinein, und ihre Vollausschlagswerte werden aus dem Gerät selbst gelesen, nicht per Katalog-Upgrade geliefert. Bei einer gewöhnlichen Karte, die Sie selbst kalibrieren, lassen Sie den Schlüssel weg.
  • activeRange ist die ausgewählte Zeile. INDEPENDENT verwendet eine { left, right }-Zuordnung (jeder Kanal seine eigene Zeile); LINKED und MONO verwenden ein einzelnes Label.

Bearbeiten Sie die Datei nur bei geschlossener Anwendung — sie wird beim Start einmal gelesen und bei jedem Speichern der Anwendung neu geschrieben, sodass Änderungen während des Betriebs überschrieben werden. Einträge ohne name (oder Bereiche ohne label) sowie unbekannte Schlüssel werden mit einer Warnung im Protokoll übersprungen, statt das Laden abzubrechen, sodass ein kleiner Fehler einen Eintrag kostet, nicht die ganze Datei. Das Löschen der Datei lässt den nächsten Start die eingebauten Standardwerte erneut anlegen, was alle von Ihnen hinzugefügten oder kalibrierten Karten verliert.

Upgrades verlieren Ihre Arbeit nie. Der vorbelegte Katalog trägt eine contentVersion; bringt eine neue Programmversion eine höhere Nummer mit, läuft die Zusammenführung einmalig und vermerkt danach die neue Nummer, sodass sie sich nie wiederholt. Für jede Katalogkarte findet sie Ihre passende Karte — anhand des Namens oder eines gemeinsamen erkannten Gerätenamens, sodass eine von Ihnen umbenannte Karte weiterhin gefunden wird — und gleicht nur deren Bereichstabelle ab: ein vom Release ergänzter Bereich erscheint in Ihrem Speicher, und ein Bereich, den Sie beide haben, wird auf den Nenn-Vollausschlag des Release aufgefrischt — außer einem von Ihnen kalibrierten Bereich, der seinen gemessenen Wert und sein calibrated-Flag behält. Eine im Release gänzlich neue Karte wird komplett hinzugefügt. Alles andere gehört Ihnen und wird nie angetastet: Ihre kalibrierten Werte, die von Hand hinzugefügten Karten und Bereiche, Ihre Liste erkannter Gerätenamen, Ihre Kanalmodi und Ihre Auswahl der aktiven Bereiche bleiben alle erhalten.

Jede Richtung — Eingang und Ausgang — trägt über ihren Gerätesteuerelementen ein eigenes Kombinationsfeld Karte:. Binden Sie ein Kartenprofil, wenn Sie eines der Folgenden benötigen:

  • mehrere Schnittstellen, zwischen denen Sie wechseln, jede mit ihrem eigenen Vollausschlag;
  • eine Schnittstelle mit umschaltbarer analoger Eingangsstufe — ein Abschwächer, eine Verstärkungsstufe oder eine DIP-Einstellung — bei der jede Stellung einen anderen Vollausschlag hat;
  • dieselbe Karte, erreicht über mehr als ein Backend, sodass eine einzige Kalibrierung wiederverwendet statt pro Backend erneut gemessen wird.

Eine einfache Soundkarte mit fester Eingangsstufe benötigt kein Profil — lassen Sie ihre Auswahl im Kombinationsfeld Karte: leer, und sie verhält sich genau so wie vor der Einführung dieser Funktion, indem sie auf den einzelnen gemeinsamen Vollausschlag zurückgreift, der den Kartenprofilen vorausging.

Das Kombinationsfeld „Karte“ und die Bearbeiten-Schaltfläche

Das Kombinationsfeld führt jedes Kartenprofil auf, das in dieser Richtung mindestens einen Bereich hat — die vorbelegten bekannten Karten eingeschlossen — sowie Neue Karte…; ein Gerät ohne Karte zeigt eine leere Auswahl. Eine kleine Bearbeiten-Schaltfläche (Stift) neben dem Kombinationsfeld öffnet den Karteneditor für die ausgewählte Karte.

Das Kombinationsfeld löst sich automatisch neu auf, sobald sich das Gerät ändert: die Anwendung gleicht den neuen Gerätenamen mit der Liste erkannter Gerätenamen jeder Karte ab und wählt, wenn eine übereinstimmt, diese aus und zeigt ihre Bereiche an. Passen mehrere, gewinnt der spezifischste (der längste passende) erkannte Gerätename. Das Auswählen des Kombinationsfeld-Eintrags und das Drücken von OK ist das, was das Gerät bindet — es hängt den exakten Gerätenamen an die Liste erkannter Gerätenamen dieser Karte an und entfernt denselben Namen aus jeder anderen Karte, sodass ein Gerät nie an zwei Karten zugleich gebunden ist.

Passt keine Karte zum Gerät, bindet die Anwendung nicht stillschweigend eine: sie bietet an, eine zu erstellen — Neue Karte für „<Gerät>“ erstellen? — und öffnet bei Ja den Karteneditor, vorausgefüllt aus dem Gerätenamen. Sie können auch selbst Neue Karte… wählen oder die Auswahl leer lassen, um das Gerät ungebunden zu halten.

Die Anwendung bindet niemals stillschweigend eine Karte. Zwei identische Schnittstellen melden identische Namen und sind für die Software nicht unterscheidbar — nur Sie wissen, welches physische Gerät in welcher Signalkette steckt, sodass eine unsichere Übereinstimmung stets zur Bestätigung angeboten wird, statt von selbst angewendet zu werden.

Eine leere Auswahl hält das Gerät ungebunden: es greift auf den einzelnen gemeinsamen Vollausschlag zurück, der den Kartenprofilen vorausging, und die Bereichstabelle bleibt ausgeblendet. Diese globale Kalibrierung wird nur aus Gründen der Abwärtskompatibilität beibehalten und im Release nach dem aktuellen entfernt — binden Sie jedes Messgerät an eine Karte, damit seine Kalibrierung im Kartenprofil liegt. Die Auswahl von Neue Karte… erstellt ein Profil, dessen erster Bereich aus der aktuell wirksamen Kalibrierung übernommen wird, sodass die neue Karte bereits auf den bisherigen Stand kalibriert startet.

Der Karteneditor

Die Stift-Schaltfläche öffnet den Karteneditor, einen kleinen Dialog, der jede Eigenschaft einer Karte enthält, außer ihren Spannungen pro Bereich (die stammen ausschließlich aus den Kalibrier-Abläufen).

EigenschaftHinweise
Kartenname Der logische Name, der im Kombinationsfeld „Karte“ angezeigt wird. Muss nicht leer und eindeutig sein.
Bereitstellung Nur Eingang, Nur Ausgang oder Beides — für welche Richtungen diese Karte kalibriert ist. Eine Karte erscheint nur in den Kombinationsfeldern der Richtungen, die sie bereitstellt. Das Einschränken einer Karte, die in einer entfernten Richtung bereits kalibrierte Bereiche trägt, fragt zuerst nach, da diese Bereiche gelöscht würden.
Kanäle Mono (ein physischer Kanal — ein einzelner Vollausschlag dient beiden Seiten) oder Stereo (zwei Kanäle).
Erkannte Gerätenamen Ein Gerätename — oder ein Fragment eines solchen — pro Zeile. Diese Karte wird gewählt, sobald irgendeine Zeile (als Teilzeichenfolge, ohne Groß-/Kleinschreibung) im vom Treiber gemeldeten Gerätenamen vorkommt; passen mehrere Karten, gewinnt die spezifischste Zeile. Diese eine Liste ist zugleich das Erkennungsmuster und die gebundenen Gerätenamen — das Binden eines Geräts hängt seinen Namen hier einfach an.

Verknüpft schaltet die Bereiche beider Kanäle gemeinsam, aber jeder Kanal behält weiterhin seinen eigenen kalibrierten Vollausschlag-Wert — die Kopplung teilt nur, welcher Bereich ausgewählt ist, nie die gemessenen Volt. Unabhängig lässt jeden Kanal seinen eigenen aktiven Bereich wählen. Eine Mono-Karte ignoriert dies.
Eingang / Ausgang — Kalibrierung vom Gerät bereitgestellt Für ein Instrument ankreuzen, das seinen eigenen Vollausschlag meldet (ein Gerät der QA40x-Klasse). Seine Bereiche bleiben umschaltbar, aber ihre Vollausschlagswerte werden aus dem Gerät selbst gelesen — das Instrument meldet seine eigene Kalibrierung. Die manuellen Kalibrier-Abläufe überschreiben sie nie, und auch ein Katalog-Upgrade liefert die Kalibrierung nicht mit: die Werte stammen immer aus dem Gerät, nie aus dem mitgelieferten Katalog.

Die Gruppen Eingang und Ausgang werden entsprechend der Bereitstellung ausgegraut — eine Karte nur für den Eingang zeigt ihre Ausgangsgruppe deaktiviert und umgekehrt.

Tabelle „Bereiche“

Ein Bereich ist eine Stellung der analogen Eingangsstufe der Karte — eine Abschwächerstufe, eine Verstärkungsstellung, eine DIP- oder Relais-Einstellung — jeweils mit ihrer eigenen Vollausschlag-Spannung. Die Tabelle führt eine Zeile pro Bereich auf:

SpalteHinweise
Aktiv-Markierung Wählt den einen Bereich, dessen Vollausschlag gerade in Kraft ist. Es ist immer genau ein Bereich aktiv; schalten Sie ihn passend zu der Eingangsstufen-Stellung, die Sie an der Hardware eingestellt haben.
Bereichsname Ein bearbeitbarer Name für den Bereich — z. B. die Abschwächer- oder Verstärkungsstellung, für die er steht (0 dB, −20 dB, ein DIP-Code).
Hinzufügen / Entfernen Fügt einen Bereich für eine weitere Eingangsstufen-Stellung hinzu oder entfernt einen.

Die Zeile hat kein Feld für die Vollausschlag-Spannung. Der Vollausschlag-Wert eines Bereichs wird hier nicht eingetragen — er wird ausschließlich gesetzt, indem der Fadenkreuz-Ablauf Kalibrieren mit dem als aktiv markierten Bereich ausgeführt wird, der den gemessenen Vollausschlag hineinschreibt.

Eine einfache Karte, die ihre Eingangsstufe nie ändert, behält eine einzige Zeile. Eine umschaltbare Schnittstelle erhält eine Zeile pro Stellung, und Sie setzen die Aktiv-Markierung jedes Mal um, wenn Sie die Hardware umschalten.

Wie viele Aktiv-Spalten die Tabelle zeigt, richtet sich nach den Kanälen der Karte und der Kopplung je Richtung, beide im Karteneditor festgelegt:

  • Unabhängige Stereo-Karte — die Aktiv-Markierung teilt sich in zwei Spalten mit den Überschriften Links und Rechts, jede trägt genau einen aktiven Bereich und ihr eigenes bearbeitbares Label, sodass die beiden Kanäle ihre eigene Eingangsstufen-Stellung getrennt verfolgen. Dies ist die E1DA Cosmos ADC, deren linker und rechter DIP-Schalter unabhängig umschalten: Stellen Sie die linke Spalte auf den Bereich passend zum linken DIP und die rechte Spalte auf den Bereich passend zum rechten. Die mitgelieferte Cosmos-Karte wird in dieser Form mit jeder aufgeführten DIP-Stellung ausgeliefert, ihre Bereichstabelle öffnet also mit beiden vorhandenen Spalten.
  • Verknüpfte Stereo-Karte oder eine Mono-Karte — eine einzelne Aktiv-Spalte, sodass beide Kanäle die Bereiche gemeinsam umschalten. (Eine verknüpfte Karte kalibriert dennoch jeden Kanal getrennt — nur die Bereichauswahl ist geteilt.)

Durchgerechnetes Beispiel — zwei Karten an einem Messplatz

Ein typischer Messplatz hat am Eingang einen E1DA Cosmos ADC, dessen DIP-Abschwächer den Vollausschlag umschaltet, und zusätzlich eine separate JLsounds-Karte im Einsatz. Binden Sie jede einmal, und ihre Kalibrierungen vermischen sich nie:

  1. Wählen Sie den Cosmos im Eingangs-Kombinationsfeld Gerät. Sein Kombinationsfeld Karte: wählt die bekannte Karte E1DA Cosmos ADC voraus — ein fertiges, in devices.yaml vorbelegtes Profil — mit einem nominalen Bereich für jede DIP-Stellung, 1.7V bis 43V, bereits an Ort und Stelle. Bestätigen Sie sie durch Auswählen und Drücken von OK. (Bei einer nicht erkannten Karte würden Sie stattdessen Neue Karte… wählen und die Zeilen von Hand hinzufügen.)
  2. Da die Cosmos-DIPs pro Kanal schalten, zeigt seine Tabelle eine Aktiv-Spalte Links und eine Rechts. Markieren Sie in jeder Spalte den Bereich passend zur DIP-Stellung dieses Kanals — die beiden Spalten verfolgen die beiden Schalter unabhängig.
  3. Kalibrieren Sie diese Bereiche über den Fadenkreuz-Ablauf Kalibrieren — am Oszilloskop ist nur die Zeile des gerade gemessenen Kanals aktiv (die andere Zeile ist deaktiviert und bleibt leer) und schreibt den gemessenen Vollausschlag dieses Kanals in dessen aktiven Bereich; messen Sie den anderen Kanal, um dessen Zeile nacheinander zu kalibrieren (die eigene Kalibrierung der FFT schreibt ebenfalls nur den gerade analysierten Kanal). Legen Sie dann einen DIP um, schalten Sie die Aktiv-Spalte dieses Kanals auf die andere Zeile und kalibrieren Sie erneut; die neue Messung landet im zweiten Bereich dieses Kanals.
  4. Wählen Sie später das JLsounds-Gerät: es trägt seine eigene Karte und seine eigene Kalibrierung, vom Cosmos unberührt.

Weil das Umlegen des DIP nichts anderes bedeutet, als umzuschalten, welcher Bereich aktiv ist, und die Werte der Karte folgen statt dem Backend, vermischt der Wechsel zwischen den beiden Karten — oder das erneute Öffnen des Cosmos unter einem anderen Backend, sobald sein Name dort gebunden ist — ihre Vollausschläge nie.

Wie eine Kalibrierung in eine Karte geschrieben wird

Die Fadenkreuz-Kalibrierungsabläufe verankern die Skala an einer bekannten Referenz — die ADC-Kalibrierung von Oszilloskop und FFT für den Eingang und die DAC-Kalibrierung des Generators für den Ausgang. Jeder dieser Abläufe schreibt den gemessenen Vollausschlag in den aktiven Bereich der aktuell gebundenen Karte. Hat das gewählte Gerät noch kein Profil, erstellt die erste Kalibrierung automatisch eines — logischer Name aus dem Gerät, ein erkannter Gerätename dafür und ein übernommener Bereich — sodass Sie allein durch das Kalibrieren ein Kartenprofil erhalten, ohne zuvor diesen Reiter aufsuchen zu müssen.

Die Kalibrierung erfolgt stets pro Kanal. Eine Stereo-Karte öffnet den gemeinsamen zweizeiligen Dialog mit einem Feld Links und einem Rechts, da keine zwei physischen Kanäle exakt gleich kalibriert sind — die Kopplung teilt nur, welcher Bereich ausgewählt ist, nie die gemessenen Werte; eine Mono-Karte zeigt eine einzelne Zeile. Auf dem Weg über das Oszilloskop ist nur die Zeile des gerade gemessenen Kanals aktiv — die andere Zeile ist deaktiviert und bleibt leer, sodass Sie jeweils einen Kanal kalibrieren; auf dem Weg über die FFT ist nur die Zeile des gerade analysierten Kanals aktiviert, da die FFT jeweils einen Kanal bearbeitet; der DAC-Weg steuert beide Zeilen an. Jede Zeile schreibt nur den aktiven Bereich ihres eigenen Kanals.

Wann die Werte wirksam werden

Der Vollausschlag des aktiven Bereichs der gebundenen Karte wird zu folgenden Zeitpunkten aufgelöst und angewendet: beim Start der Aufnahme (Eingang), beim Start des Generators (Ausgang) und beim Schließen dieses Dialogs mit OK. Ab diesem Moment steuert der aufgelöste Wert die absolute dBV-Achse der FFT, die Spannungsanzeigen des Oszilloskops und die Ausgangsskalierung des Generators. Ein Gerät ohne Profil greift auf den einzelnen gemeinsamen Vollausschlag zurück (ein veralteter Rückfall, der entfernt wird — binden Sie eine Karte), sodass sich nichts ändert, bis eine Karte gebunden oder kalibriert wird.

Ein Wert wird auch sofort wirksam, wenn Sie den Kalibrierdialog mit der Schaltfläche Kalibrieren schließen: der neue Vollausschlag wird in devices.yaml gespeichert und über die Live-Kartenbindung an jeden Verbraucher weitergegeben — die Skalierung des Oszilloskops, die dBV-Achse der FFT und die Amplitudengrenze des Generators — ohne Neustart.

Jede Karte löst jeden Kanal zu seinem eigenen kalibrierten Vollausschlag auf, sodass jede Oszilloskop-Spur und -Messung den Wert ihres eigenen Kanals verwendet und die absolute dBV-Achse der FFT dem analysierten Kanal folgt. Eine unabhängige Karte kann die beiden Kanäle zusätzlich auf unterschiedliche Bereiche stellen; eine verknüpfte Karte hält beide auf demselben Bereich, verwendet aber weiterhin den eigenen gemessenen Wert jedes Kanals.

Oszilloskop

Nachleuchtdauer Digitales Phosphor-Nachleuchten — wie lange jede durchlaufende Spur sichtbar bleibt, bevor sie verblasst, wie bei einem analogen Oszilloskop. Wählen Sie Off; eine voreingestellte Abklingzeit — 0.5 s, 1 s, 2 s, 5 s, 10 s, 15 s oder 20 s (eine alte Spur verblasst nach dieser Zeit auf ~37 % und nach der dreifachen Zeit auf ~5 %); ∞ (Spuren verblassen nie und sammeln sich an, bis sich die Ansicht ändert); oder Manual (verwendet das Feld darunter). Macht Trigger-Jitter und Rauschen als verblassende Hüllkurve sichtbar. Erfordert GPU-Beschleunigung (siehe Erscheinungsbild); ohne Wirkung im CPU-Modus.

Spurlinienbreite, px Strichstärke der Betrags-, Phasen-, RIAA-Referenz- und Vergleichskurven.
Maximale Analysefrequenz, % Nyquist Begrenzt die obere Grenze der Ansicht auf diesen Bruchteil von Nyquist (96–100 %); unter 100 % wird der Bereich abgeschnitten, in dem die Sweep-Dekonvolution abfällt.

Kerbfilter für Netzbrumm zulassen Wenn aktiviert, wird bei jeder Oberwelle der gewählten Netzfrequenz interpoliert, um Brummspitzen aus der angezeigten Kurve zu entfernen — ohne erneute Messung.
Netzfrequenz Die Netzgrundfrequenz (50 / 60 Hz), deren Oberwellen ausgekerbtt werden, wenn die obige Option aktiviert ist.
