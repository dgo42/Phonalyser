Генератор

На цій сторінці описані елементи керування генератором. Про те, як він синтезує сигнали всередині — пряме цифрове синтезування, ядра форм сигналу, свіпи та активна компенсація спотворень — дивіться Теорія роботи ▸ Сигнальний генератор.

Формує тестові сигнали, що надходять на налаштований вихідний пристрій. На цій панелі співіснують два взаємовиключних двигуни: тоновий генератор (синус / свіп / шум / тощо) та програвач аудіофайлів. Запуск одного зупиняє інший.

Кожне числове поле тут приймає значення чотирма способами: введіть його вручну, прокрутіть коліщатко миші, натисніть стрілки ▲/▼ або — якщо поле у фокусі — натисніть клавіші ↑/↓ (той самий крок, що й у стрілок).

  1. Індикатор ON AIR. Сірий у режимі очікування; LED вмикається і текст блимає, поки генератор випромінює сигнал — Індикатор ON AIR.
  2. Форма сигналу. Селектор форми сигналу (синус, подвійний тон, трикутник, прямокутник, білий / рожевий шум, лінійний та логарифмічний свіп, компенсований синус) — Форма сигналу. Навколишні поля переналаштовуються залежно від форми (прогальність для трикутника/прямокутника, елементи керування свіпом для свіпів).
  3. Прив'язка до бін FFT. Округлює вихідну частоту до найближчого бін FFT, щоб тон був когерентним з аналізатором — основа петлі захоплення частоти (Теорія ▸ фазовий акумулятор). Дивіться Прив'язати частоту до найближчого.
  4. Амплітуда (RMS). Рівень виходу у вольтах RMS відносно калібрування DAC; селектор одиниць приймає µV/mV/V та dBV — Амплітуда (RMS).
  5. Корекції. Завантажує файл компенсації гармонік, щоб форма компенсованого синусу активно скасовувала виміряні спотворення ланцюга — Корекції.
  6. WAV-файл. Зберегти як… експортує поточний сигнал у WAV/AIFF/FLAC; Завантажити з… + В циклі відтворює файл (прапорець «В циклі» повторює його).
  7. Калібрування DAC та відтворення. Кнопка з перехрестям відкриває діалог калібрування DAC; зелений трикутник — це Відтворити / Зупинити. Запуск тону зупиняє відтворення файлу і навпаки.
  8. Вихідний канал. Комбо Обидва / Лівий / Правий у рядку заголовка вибирає, який канал DAC несе сигнал; невибраний канал відтворює цифрову тишу — Вихідний канал.

Заголовок

Форма сигналу

Випадаюче комбо з одинадцятьма формами сигналу. Кожен запис має маленьку піктограму, що показує форму сигналу. Зміна форми переналаштовує навколишні елементи керування — поле прогальності вмикається для Rectangle та Triangle, елементи керування свіпом з'являються для Linear sweep та Log sweep, поле частоти вимикається для варіантів шуму.

Вихідний канал

Комбо у верхньому рядку заголовка — у рядку «Форма сигналу», над селектором форми сигналу та поряд з індикатором ON AIR —, що вибирає, який канал DAC несе згенерований сигнал: Обидва, Лівий або Правий. Невибраний канал відтворює цифрову тишу, тож ви можете вести лише один бік стереопристрою — чи один канал випробовуваного пристрою — окремо. Це діє наживо: перемикання каналів під час відтворення тону набуває чинності одразу, без зупинки генератора.

Індикатор ON AIR

LED і текст ON AIR у верхньому правому куті панелі. Кожного разу, коли тоновий генератор АБО програвач аудіофайлів керує виходом, LED горить суцільним червоним і текст ON AIR блимає. Обидва стають сірими, коли нічого не відтворюється — тобто індикатор показує з першого погляду, чи програма зараз випромінює звук.

Частота

Частота

Вихідна частота для періодичних форм сигналу (вимкнена для варіантів шуму). Приймає Hz та kHz; число без суфікса читається як Hz, а дисплей перемикається на kHz вище 1 kHz.

Мітка може показувати анотацію у дужках — наприклад, Frequency (1000.122 Hz) — коли корекція прив'язки до бін FFT або цілочисельний період відліку (для Rectangle) дає випромінювану частоту, дещо відмінну від введеної. Значення у дужках — це фактична випромінювана частота.

Прив'язати частоту до найближчого

Прапорець. Якщо увімкнено, випромінювана частота прив'язується до найближчого бін FFT для поточної довжини FFT-аналізатора. Корисно для чистих спектральних вимірювань: при увімкненій прив'язці основний тон потрапляє точно на бін і витік вікна не забруднює оцінки гармонік.

Прогальність

Активна лише для Rectangle (частка часу у стані «високий») та Triangle (частка часу наростання) у відсотках. Кожна форма сигналу запам'ятовує власне значення, тому перемикання між Rectangle і Triangle відновлює останнє значення кожної.

Лише для Rectangle прогальність адаптується до того, що DDS може фактично видати: його крок +1/−1 може потрапляти лише на цілий відлік, тому найдрібніший крок прогальності — один відлік на період — f / fs (вихідна частота ÷ частота дискретизації). Приклад: 10 kHz при 384 kHz дає 38.4 відліки на період, тому найменший крок ≈ 1/38.4 ≈ 2.63 %, а більш дрібне введене значення прив'язується до найближчого досяжного кроку. Мітка тоді показує адаптовану прогальність у дужках — наприклад, Duty cycle (2.632 %).

Triangle використовує справжній безперервно-фазовий DDS (його відліки лежать точно на рампах, тому кут є субвідліковим), тому його прогальність точна — без квантування і без дужок. Дивіться Теорія ▸ квантування прогальності.

Подвійний тон (IMD)

Видимий лише при виборі Dual tone. До єдиного поля частоти додаються друга частота та баланс амплітуд між двома тонами (кожний у відсотках; типовими тестами на інтермодуляцію є пари 19 kHz + 20 kHz або 60 Hz + 7 kHz). Комбінований вихід перенормується до введеного значення V RMS незалежно від розподілу, тому пара 50/50 не тихіша за одиночний тон за тих самих налаштувань. Обидва тони можна прив'язати до бін FFT незалежно, а FFT-аналізатор вимірює їхні продукти інтермодуляції — дивіться Теорія ▸ подвійний тон та Теорія ▸ два тони.

Подвійний тон (компенсований)

Варіант Dual tone із корекцією інтермодуляції — двотоновий аналог Sine compensated. Кожен продукт спотворення двотонового сигналу — гармоніки кожного тону та їхні продукти інтермодуляції — знаходиться на a·f1 + b·f2 для цілих a, b, тому генератор попередньо спотворює вихід протифазним коригувальним тоном на кожному такому продукті, щоб скасувати його на стороні аналізатора. Корекції вимірюються автоматично за допомогою замкненого майстра предспотворення — кнопки-палочки ★ поруч із елементом запису FFT-аналізатора — та потім застосовуються в реальному часі. Вибір цієї форми з комбо без завантажених виміряних корекцій просто видає два чисті тони, так само як Sine compensated повертається до чистого синусу.

Свіп / чірп

Видимий лише при виборі Linear sweep або Log sweep. Замінює єдине поле частоти блоком параметрів свіпу.

Початкова частота

Частота, з якої починається чірп (Hz / kHz).

Кінцева частота

Частота, на якій закінчується чірп (Hz / kHz).

Тривалість

Загальна довжина чірпу в секундах.

Наростання

Секунди. Рампа амплітуди на початку чірпу, що пригнічує клацання, яке спричинив би різкий стрибок амплітуди.

Спад

Секунди. Те саме, що й наростання, але в кінці чірпу.

Цикл

Прапорець. Якщо увімкнено, свіп перезапускається одразу після завершення, у безперервному циклі.

Амплітуда

Амплітуда (RMS)

Рівень виходу, що зберігається внутрішньо як вольти RMS. Одиниці: µV, mV, V та dBV (без урахування регістру); число без суфікса читається як вольти. Метричний дисплей автоматично масштабується (µV / mV / V), щоб число залишалося читабельним; введення значення dBV залишає поле в dBV (автомасштабування ніколи не перемикається на dBV самостійно).

Примітка: dBV відноситься до 1 V RMS незалежно від пристрою — x dBV = 10x/20 VRMS.

Дитеринг

Визначає, скільки трикутного (TPDF) дитерингу додається безпосередньо перед квантуванням виходу — Off, або глибину від 1 LSB до розрядності виходу. Задавайте в bits або додайте суфікс dBV, щоб задати рівень шуму, який створює дитеринг; підпис показує іншу одиницю, а коліщатко/стрілки крокують ±1 bit (режим bits) або ±10 dBV (режим dBV), з Off угорі.

dBV — це фізичний рівень шуму дитерингу, прив'язаний до повної шкали DAC: введення, скажімо, −100 dBV ставить шум, який вимірює FFT, на −100 dBV — з будь-яким вікном аналізу, адже шумові метрики аналізатора враховують шумову смугу вікна — за умови, що FFT використовує некогерентне (за потужністю) усереднення (когерентне усереднення скасовує шум і читається значно нижче). Дитеринг руйнує періодичні патерни квантування при дуже низьких рівнях виходу.

Калібрування DAC (кнопка з перехрестям)

Кнопка з перехрестям у нижньому лівому куті панелі відкриває спільний діалог калібрування DAC, який прив'язує шкалу Амплітуда (RMS) — напругу у вольтах RMS, яку DAC видає для цифрової повної шкали, — до рівня, який ви вимірюєте на виході. Задайте генератору відому амплітуду, зчитайте фактичний вихід надійним вимірювачем і введіть це показання.

Введіть виміряну амплітуду сигналу в nV / µV / mV / V. Для стереокарти діалог має рядок Лівий та рядок Правий — калібрування завжди поканальне, оскільки два фізичні канали DAC ніколи не збігаються точно, — а для монокарти має єдиний рядок; кожен рядок записує лише активний діапазон свого каналу. Карта з налаштуванням Зв'язок: Пов'язані все одно калібрується поканально — «Пов'язані» ділять лише те, який діапазон вибрано.

Гучність Windows є частиною калібрування. Установіть гучність цього вихідного пристрою в параметрах звуку Windows на 100 й більше ніколи її не рухайте після калібрування: ексклюзивні режими WASAPI та WDM-KS оминають програмний мікшер, але на багатьох USB-інтерфейсах цей повзунок усе одно керує внутрішньою апаратною гучністю пристрою, тож пізніший зсув беззвучно перемасштабує виміряну вами повну шкалу. Виняток: карта, що використовує положення повзунка для перемикання режимів — E1DA Cosmos вище положення 49 зв'язує свої канали (правий — основний вхід, лівий несе той самий сигнал на 6 дБ нижче) — має стояти там, де вимагає її режим, і лишатися там.

Корекції

Файл предспотворення (.dpd)

Необов'язковий файл предспотворення, що описує компенсацію DAC. Однотоновий файл містить перелік комплексної корекції для кожної гармоніки; двотоновий файл містить продукти інтермодуляції у вигляді коефіцієнтів (a, b). Генератор попередньо спотворює вихід так, щоб перелічені спотворення скасовувалися на стороні аналізатора. Використовуйте кнопку відкриття файлу для вибору .dpd; поле лише для читання тоді показує завантажений шлях, а кнопка очищення вивантажує його. Ці файли створюються майстром предспотворення панелі FFT (кнопка-паличка ★ поруч із елементом запису) — дивіться Подвійний тон (компенсований) та Sine compensated.

Експорт WAV

Тривалість

Секунди. Довжина аудіо для запису при використанні Save to. Незалежна від живого випромінювання — файл рендериться за один прохід із поточними налаштуваннями генератора.

Зберегти як…

Поле шляху лише для читання + кнопка збереження. Клацання відкриває діалог збереження; розширення обраного файлу визначає формат (.wav / .flac / .aiff / .aif). Підтвердження негайно записує файл із поточними налаштуваннями генератора та вказаною вище тривалістю.

Записаний файл є ідеальним, математично точним сигналом — синтезованим цифровим способом і вільним від будь-яких спотворень DAC, підсилювача або кабелів. Використовуйте його як еталон або для подачі на інший прилад з відомо чистим джерелом. Дивіться Теорія ▸ збереження сигналу.

Відтворення WAV

Завантажити з… + В циклі

Відтворює наявний аудіофайл на вихідний пристрій. Кнопка відкриття аудіо вибирає файл — будь-який WAV / AIFF / FLAC, не лише файли, збережені цією програмою. Прапорець В циклі повторює файл по досягненні кінця; перемикач живий — зміна під час відтворення набуває чинності в наступній точці циклу.

Відтворити / Зупинити файл

Малий LED відтворення поруч із полем шляху. Горить під час відтворення файлу, темний в іншому випадку. Запуск відтворення файлу зупиняє тоновий генератор, якщо він був запущений (і навпаки для головної кнопки відтворення).

Головна кнопка відтворення

Відтворити / Зупинити

Велика кнопка відтворення, закріплена в нижньому правому куті панелі. Запускає тоновий генератор із поточною формою / частотою / амплітудою. Під час роботи піктограма показує активний стан відтворення і індикатор ON AIR блимає. Повторне натискання зупиняє випромінювання. Запуск головного програвача зупиняє програвач WAV-файлів, якщо він був запущений.
